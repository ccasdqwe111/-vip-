# 新版本双码率云转码视频M3U8切片系统开源修复版源码

源码获取：ym7k.com/19741/

这套是基于 FFmpeg 的 HLS 云转码切片平台，主打**双码率自适应 M3U8**，市面流通修复版，修复旧版转码报错、外链无法播放、水印失效、队列卡死等 BUG，开源无加密，私有化部署，常用于短剧系统、点播网站、H5 播放器、私域视频分发，支持对接 OSS、CDN 分发视频流。

## ✅ 运行环境

- 后端：PHP（PHP7.4/PHP8 均可，依赖 FFmpeg）
- 数据库：MySQL5.7+
- 依赖：FFmpeg（核心转码程序）、Redis（任务队列，防并发卡死）
- 存储：本地存储、阿里云 OSS、腾讯云 COS、对象存储
- 服务：Nginx，服务器建议 Linux，Windows 兼容差、稳定性低

## ✅ 核心功能

1. **双码率自适应 HLS（核心）**
上传原视频自动输出两路清晰度（标清 + 高清），生成 master 主索引 m3u8；播放器根据用户网速自动切换码率，网速差自动切低清，流畅不卡顿，是短剧、点播主流方案。支持自定义分辨率、码率、切片时长。
2. **多格式上传转码**
支持 MP4、MOV、MKV、FLV 等主流视频格式，统一转码为 H.264/H.265 格式的 HLS TS 切片。
3. **任务队列管理**
异步转码队列，多任务排队，防止服务器 CPU 跑满；后台查看任务：等待中、转码中、已完成、失败日志，失败任务支持一键重转。
4. **水印管理**
文字水印、图片水印，自定义位置、透明度、字号。
5. **防盗 & 播放权限**
提供 Token 防盗链、Referer 防盗以及过期链接功能，有效防止 m3u8 资源被爬取盗链；同时支持 HLS AES 加密切片（增值服务）。
6. **文件存储与 CDN**
转码完成自动同步到对象存储，支持 CDN 加速分发，减轻源站带宽压力；可设置转码完成自动删除原文件，节省磁盘。
7. **上传方式**
本地上传、远程拉取 URL 转码、API 外部调用上传（适合对接短剧 CMS、商城视频模块）。
8. **后台管理面板**
视频列表、转码记录、存储配置、FFmpeg 参数自定义、水印配置、防盗链设置、上传限制、公告、日志查看。
